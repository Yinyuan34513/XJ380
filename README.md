# XJ380(Code Singularity)操作系统
## 开发者须知
1、严禁泄露源代码及镜像。
2、Push代码请推送到自己的分支上。
3、严禁擅自合并分支。
4、main分支为主分支，每个主分支版本要新建一个分支专门储存。
5、编译环境为Ubuntu 24.04。请严格按照规定配置开发环境或使用统一配置的虚拟机。
6、更新日志按照BV1作为规范（版本+【状态】 日期+用户名），状态分为 已实机测试 \ 已虚拟机测试 \ 通过编译未测试 \ 未通过编译未测试 \ 暂未编译

## 环境配置
### 环境所用软件
- mingw-w64
- x86_64-elf-tools
### mingw-w64
1、在随便一个位置打开终端（例如桌面）
2、输入sudo apt install gcc-mingw-w64-x86-64
3、输入密码（你看不见你输入的密码，直接打，不用管），统一配置的密码为"hello1115"。
4、等待安装完成。
